# 知行工作台

> 知行工作室 出品 · 个人桌面工作台应用 v3.1
> 致 虚 极 / 守 静 笃

一款简约、可扩展的 Windows 桌面效率工具。集成快捷启动、待办管理、笔记记录、番茄钟计时等功能。
基于 Python + CustomTkinter 开发，界面采用扁平化简约设计风格，支持首次启动自定义密码登录与数据加密存储。

## 功能特性

- **密码登录**：首次启动引导设置自定义密码（≥ 6 位）；使用 PBKDF2-HMAC-SHA256 + AES 加密存储待办 / 笔记 / 快捷启动等敏感数据
- **快捷启动**：分类管理「软件 / 网址 / 系统命令」三种类型项目；支持图标自动提取、系统预设一键导入、分类拖拽排序、分类右键重命名/删除、新增类型与视图大小跨会话记忆
- **待办管理**：任务增删改查、完成状态切换、番茄钟计时联动
- **笔记记录**：随手记录灵感和想法，支持标题 + 内容编辑与按时间排序
- **番茄钟**：25 分钟专注 / 5 分钟休息循环；基于绝对时间戳（wall-clock）抗锁屏/最小化/切页/加任务延迟；支持暂停 / 继续 / 重置 / 立即继续 / 跳过 / 延后 5 分钟
- **实时时钟 + 双语金句**：首页欢迎栏两栏式扁平化布局（左问候+中英双语每日金句，右 Win11 风格 36px 蓝色时钟+日期）
- **主题切换**：深色 / 浅色 / 跟随系统（SegmentedButton 切换）
- **窗口停靠**：拖到屏幕左/右边缘 ≤ 14px → 鼠标离开 400ms 自动收为 6px 窄边；鼠标碰到 180ms 自动展开（QQ 式靠边收纳）
- **自动锁屏**：每 30s 轮询 idle 时间，阈值（1/3/5/10 分钟）到后自动显示 🔒 锁屏界面；若开启窗口停靠则同步收纳至托盘，防止走开被偷看
- **导航拖拽 + 分类拖拽**：首页 / 设置 / 关于固定位置，其余导航项拖拽排序；快捷启动分类标签也支持拖拽排序（更名开关关闭时锁定）
- **托盘最小化**：关闭窗口自动收纳到系统托盘（pystray），后台运行不干扰；双击托盘 / 右键菜单「显示主窗口」恢复
- **本地存储**：安装版 `~/.zhixing_workbench/`、便携版程序同级 `data/`；支持便携版与安装版数据自动迁移合并
- **系统集成**：进程级 + 窗口级 AppUserModelID（v3），任务栏图标 / 固定到任务栏 / 跳转列表正确关联

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.10+ |
| UI 框架 | CustomTkinter 5.2+ |
| 图像处理 | Pillow (PIL) |
| 数据加密 | PBKDF2-HMAC-SHA256（100000 次迭代派生密钥）+ AES 流式加密 |
| 系统托盘 | pystray |
| 打包 | PyInstaller 6.x (onedir) + version_info.txt |
| 安装包 | NSIS 3（System.AppUserModel.ID 同步写入快捷方式） |
| 系统集成 | ctypes + Shell32 (SetCurrentProcessExplicitAppUserModelID / SHGetPropertyStoreForWindow) |

## 快速开始

### 从源码运行

```bash
pip install -r requirements.txt
python main.py
```

> 首次启动：弹出「欢迎使用知行工作台」窗口，引导你输入两次密码（至少 6 位）→ 点「完成设置」→ 进入主界面。**没有默认密码。**

### 打包构建

```bash
# 便捷版 (onedir)
pyinstaller --clean --noconfirm ZhixingWorkbench.spec

# 安装版 (需先安装 NSIS 3)
"C:\Program Files (x86)\NSIS\makensis.exe" setup_installer.nsi
```

## 数据存储

- **安装版**：用户主目录下 `~/.zhixing_workbench/`（多用户互不干扰）
- **便携版**：程序同级 `data/` 文件夹（放到 U 盘即用）
- 便携版启动时若检测到安装版有数据，会自动询问并合并迁移
