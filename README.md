# 知行工作台

> 知行工作室 出品 · 个人桌面工作台应用 v3.0
> 致 虚 极 守 静 笃

一款简约、可扩展的 Windows 桌面效率工具。集成快捷启动、待办管理、笔记记录、番茄钟计时等功能。
基于 Python + CustomTkinter 开发，界面采用扁平化简约设计风格，支持密码登录保护与数据加密存储。

## 功能特性

- **密码登录**：安全的密码保护机制，数据加密存储，支持自定义修改密码
- **快捷启动**：分类管理应用 / 系统工具 / 网页书签，支持图标自动提取，一键直达
- **待办管理**：任务增删改查、完成状态切换、番茄钟计时联动
- **笔记记录**：随手记录灵感和想法，方便随时查阅
- **番茄钟**：25 分钟专注 / 5 分钟休息循环，锁屏后基于绝对时间戳自动恢复，支持暂停 / 继续 / 重置
- **实时时钟**：首页 Win11 风格时钟（时间上日期下，精确到秒）
- **主题切换**：深色 / 浅色 / 跟随系统
- **窗口停靠**：拖到屏幕边缘自动收纳（类似 QQ）
- **自动锁屏**：无操作超时自动锁定，防止走开被人偷看
- **导航拖拽**：非固定项支持拖拽排序，首页 / 设置 / 关于固定位置
- **托盘最小化**：关闭窗口自动收纳到系统托盘，后台运行不干扰
- **本地存储**：数据安全保存在本地，隐私无忧

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Python 3.10+ |
| UI 框架 | CustomTkinter 5.2+ |
| 图像处理 | Pillow (PIL) |
| 数据加密 | PBKDF2-HMAC-SHA256 + AES 流式加密 |
| 打包 | PyInstaller (onedir) |
| 安装包 | NSIS 3 |
| 系统集成 | ctypes (AppUserModelID / Shell API) |

## 快速开始

### 从源码运行

```bash
pip install -r requirements.txt
python main.py
```

### 打包构建

```bash
# 便捷版 (onedir)
pyinstaller --clean --noconfirm ZhixingWorkbench.spec

# 安装版 (需 NSIS 3)
makensis setup_installer.nsi
```

## 数据存储

- 安装版：用户主目录下 `~/.zhixing_workbench/`
- 便携版：程序同级 `data/` 文件夹
- 支持便携版与安装版数据自动迁移合并
